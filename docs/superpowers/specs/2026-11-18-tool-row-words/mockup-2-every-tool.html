Every tool, and what goes wrong

Second screen: the tools the first one didn't cover, each with every error case the server tells apart (or should) and the words a person would read. Click a row to open or close it. The grey line under each sentence names the case for you; it isn't shown in the app. The English in the Today column is shaped like the real text, not copied from it. The row language switch changes only what a person would read.

The rule, as agreed
  • Opening a row gives a little more than the tool's name: the things it found or touched, by their own names, in plain words.
  • Never the model's side: no argument names, ids, codes, error text or notes written for the model.
  • Every error case the server tells apart has its own sentence in English and Hungarian, shown once. A case without one gets that tool's fallback line. The raw error stays in the server log, for fixing.
  • A red ✕ only when something broke. A stop the app made on purpose, or a setting the person can change, is a quiet –.
  • A row with nothing more to say doesn't open.
