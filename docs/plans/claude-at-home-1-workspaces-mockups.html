Agreed screens for Personal Instructions, Project Instructions, Folder Knowledge, the home projects row, the Info popover and the Parallel allowance. Spec: docs/plans/claude-at-home-1-workspaces-spec.md.

9 · Parallel free monthly allowance (admin)

A setting in Integrations & keys → Web research (default $5.00), and an allowance meter on the System analytics Parallel API tab. Users see no change: their Parallel cost is $0 until the allowance is used up.

Parallel free monthly allowance
Parallel calls cost nothing to users until the whole server's usage passes this amount in a calendar month. After that they count as normal. Set to 0 to always count them.
