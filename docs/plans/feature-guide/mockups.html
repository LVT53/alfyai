Show me

The drawings would be built from the app's own pieces: the same icons and colours, and every word taken from the app's own dictionary. Switch the labels to HU or the theme to dark: nothing is redrawn and nothing is translated by hand. If a button's wording changes, the drawing changes with it. If a screen's layout changes a lot, its drawing has to be updated in the same change, which is cheap because it is code, not an image.
