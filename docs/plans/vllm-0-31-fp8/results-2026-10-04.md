## Boot facts (new server)

`kv_cache_dtype='fp8'`; `Model loading took 76.09 GiB`; `Setting attention block size to 3200 tokens` (was 1600 —
FP8 halved the page); `Available KV cache memory: 10.15 GiB`; `GPU KV cache size: 628,636 tokens, Maximum

model='/drafter', num_spec_tokens=3)`; boot to `Application startup complete` in **180 s**.

## Notable decisions / deviations

- **Environment:** Docker track (PyPI had no `vllm==0.31.0`). Image pulled by pinned digest.
- **`VLLM_PLE_*` removed in v0.31.0** → PLE CPU offload is now `--engram-config '{"cpu_offload": true}'`.
  Unit corrected accordingly in step B3/B5.
- **Download tool:** the `hf` CLI stalled at ~4 MiB/s; switched the remaining files to parallel `curl`
  (~188 MiB/s). No integrity impact — all 220 files re-verified by sha256.
- **T4 tool-call 9/10 on first C5 run was a flake** (item #4, "temperature in London"); re-run gave 10/10 and 6/6
  manual trials. MTP/batched serving introduces minor nondeterminism even at temperature 0.
- **`t7.sh` needs `DOC_PATH`** (a markdown file) exported for `verify-tools.mjs`/`verify-tools-2.mjs`; without it
  they fail on `readFile(undefined)` *before any model call*. With `DOC_PATH` set, both pass.
- **Swap** fills during startup (the ~52 GB pinned PLE table + boot), then is stable and not thrashing
  (`si/so≈0`); MemAvailable stays ~63 GiB. Not an abort condition, but the box now runs with little swap headroom.
