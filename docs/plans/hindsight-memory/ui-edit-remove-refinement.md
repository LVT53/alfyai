This study chooses Edit. The editor says “Change the wording or delete details you don’t want remembered.” A collapsed View saved version supplies comparison without repeating the entire fact by default. Save returns to the updated detail. Removing “green” from the touring-kayak memory keeps ownership and the separate white racing kayak. This remains a real semantic removal request for the eventual backend, not merely cosmetic rewriting or a weakened correction contract.

Remove is a separate confirmation showing the exact memory, Cancel and Remove. No partial-removal branch. Plain copy explains that conversations remain and telling Alfy again later may create a new memory. There is no promise of permanent topic suppression or physical source erasure.

Conversation evidence replaces Where this came from: a single clickable conversation row, followed by You wrote and the source excerpt. Manual edits are attributed on the current memory. The original quotation is preserved and the detail explains when the memory has been edited since; editing memory never fabricates a matching chat quotation. Previous wording is collapsed with plain “Alfy no longer uses this version” copy. Evidence displayed for owner inspection is not automatically eligible for answer context; the existing removal/admission boundary still applies.
