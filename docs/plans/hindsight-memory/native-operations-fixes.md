App and inference transport verify permitted private addresses, resolve the Docker host gateway per request, pin the actual socket address, refuse redirects and exclude public or link-local destinations. The curation dispatch fence still runs after any asynchronous alias resolution. The Python transport ignores ambient proxy variables.

## Follow-up on ambient proxies and late configuration

The real Node child regression supplies an ambient proxy and enables `--use-env-proxy`. Ordinary Fetch reaches the synthetic proxy and exposes the synthetic bearer in the positive control. The protected GET and curation-shaped POST connect directly to the private listener with zero proxy connections. A protected redirect fails without reaching the redirect destination. Production uses explicit built-in HTTP(S) agents for both paths and retains the immediate pre-dispatch curation fence. Consulted the official [Node proxy configuration](https://nodejs.org/learn/http/enterprise-network-configuration) and [HTTP agent](https://nodejs.org/api/http.html#new-agentoptions) docs. [Proxy probe results](native-acceptance/private-proxy-results.json)

The application records a pending bank configuration intent before its single native PATCH. The pinned route creates the bank, then persists the requested configuration. Exact readback positively settles this unique write. Reset carries the pending marker in the existing opaque cleanup intent and withholds terminal success while the bank is absent or only partly configured. After exact readback, cleanup records settlement, deletes the native bank and verifies absence. Process or transport loss before submission may leave a conservatively pending intent after retries. Older unversioned bindings may have several outstanding metadata writes, so they remain pending for explicit reconciliation. The narrow race concerns opaque bank metadata and generic configuration only. The app's existing second fence prevents the user text write.

Eight focused suites passed 121 tests. The real-job regression held the server-side outcome, reset, observed absent and then partial config, and verified one later delete after exact config arrived. A separate fixture exhausted bounded retries after the synthetic first submission was lost, asserted zero resubmission and carried its marker into reset. The pinned native smoke passed against a fresh bank using the single PATCH and admitted both EN/HU facts through the real app evidence gate. A separate real curation SDK call passed its dispatch fence and parsed the synthetic JSON returned through the direct gateway.
