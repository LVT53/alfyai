# Isolated zero-review Memory replay

The isolated replay published 26 automatically selected assertions and two previously corrected, owner-authored facts. The frozen matched benchmark scored **2/2 for legacy and 2/2 for native Memory**. The small benchmark establishes parity on those cases. An independent audit passed 39 of the 40 published observations on substance and flagged one transient assertion. The sampled skips included seven possible misses. This run does not establish that zero-review production migration is safe or complete.

## Inputs and method

- One authorized account supplied 285 eligible chat messages from the frozen 546-message cohort, plus two verified prior Memory edits. The other 261 message bodies were excluded before extraction and were never loaded into the replay. The allowed messages span April 27 to November 18, 2026 UTC.
- The app database copy contained one isolated account alias. Native calls used distinct staging banks and the approved local Qwen gateway. The restricted executor reached staging, blocked connections to three other endpoints, and could not open three production paths. Checks of production job and admitted-source fingerprints agreed before and after publication.
- Pinned native Hindsight dry-run extraction handled all 285 messages. The empty preview bank contained zero facts and pending operations when extraction ended. A second pass used frozen selection rules and required an exact quote from the matching message and the original scope. The policy admitted enduring, explicit facts or project decisions, skipped weak material and held consequential uncertainty. Benchmark questions and answers were unavailable to selection.
- The staging app cut over after both protected edits settled. It then delivered the automatically selected assertions through the usual Memory source jobs, retaining each source date and scope. No new human review, Keep, Edit or Discard occurred. Held drafts went to a protected audit file and stayed outside recall.

The 26 automatic selections came from 23 distinct messages, about 8% of the 285 allowed messages. Twelve selections were personal and 14 were project-scoped. Ten skips came from two classifier batches whose responses could not be validated. All 29 delivery jobs succeeded, including one provision and 28 source jobs. Published observations passed the app's source-support checks. No pending native operations remained at verification.

The two held clusters warranted a review in independent assessment. The owner cohort did not exercise the 10-cluster cap. A separate test ran the frozen selector’s grouping and cap code on synthetic, pre-graded inputs spanning personal Memory and two projects. Fifteen held drafts, including two duplicates, formed 13 distinct ambiguity clusters. The account-wide cap selected 10 clusters for review across the three scopes. Three clusters containing four drafts remained held outside the review queue and automatic publication, with no resolution recorded. The control also skipped a duplicate explicit admission. It used no inference and made no native writes. A separate audit found no full overlap with known withdrawn wording. Two short phrase overlaps were already present in the explicitly approved corrections. The migration inventory flagged missing prior wording for 78 of 110 recorded exceptions. The known-wording checks cannot rule out a paraphrase of an undocumented withdrawal.

## Benchmark and quality limits

| Evaluation | Result |
| --- | --- |
| Frozen matched legacy versus native | 2/2 each |
| Supplemental wrong-scope personal control | Passed in both arms |
| Supplemental personal and project ownership probes | Both inconclusive in each arm because the supporting assertions were not admitted |
| Independent audit of all automatic selections before delivery | 25/26 passed. One was a transient assertion |
| Independent audit of all published observations | 40/40 had exact source support. 39/40 passed substantive review. One was transient. No added ownership, stale date or unjustified change was detected |
| Independent audit of 24 sampled skips | 7 possible misses. The sample does not estimate prevalence across all skips |

The original two cases used the narrow frozen legacy baseline. The three supplemental cases compared the isolated native replay with the protected-subset legacy mirror. Answers were graded blind to the arm, using the same local Qwen model. Both comparisons used the same Qwen alias and generation settings for answer generation. The original legacy arm ran through the approved production-local gateway before the isolated test. The native arm and both supplemental arms ran through the staging-local gateway. The test did not measure comparable latency or overall recall from the full legacy profile. An accepted source and a structurally valid support link verify delivery and provenance. Semantic correctness is evaluated separately because native retain and consolidation can split or rephrase an assertion.

## Operational state

The isolated run made no production writes. Production kept serving under legacy Memory authority while the already prepared native migration remained inactive. The stopped production preview was neither resumed nor retried. No changes were pushed or deployed during this test.

The authorized host retains the source seal, dry-run, selection and publication receipts, and benchmark evidence under account-only permissions. A ten-file checksum manifest was independently verified. Raw messages, facts, evaluation questions and answers are omitted from this report.
