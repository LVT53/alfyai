Where the experiment stands

The real version gate rejected a stale worker, suppressed old memory during rebuilding, and loaded its published revision in a new process. Hindsight reprocessed the edited source without recovering the removed colour.

The semantic layer still made mistakes. One localized-edit result silently changed a newly edited green bicycle to the earlier blue correction. The revision gate cannot detect that mistake: it is current work with incorrect meaning.

The prototype rebuilds a whole scratch bank and temporarily withholds memory while doing so. This makes the boundary testable, but its cost and availability are not a production design decision.
