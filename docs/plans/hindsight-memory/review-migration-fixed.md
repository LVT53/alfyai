Despite the verified old project source and the move event, both facts reached a personal-bank retain and its published snapshot, and inventory labeled the source eligible. ## Earlier P1 — Unchanged history restored a removed or corrected fact

The following records the original failure and repair target. The original four route cases now pass, subject to the separate scope and chronology findings above.

Preparation assigns a new document ID to the same saved chat message after withdrawal or a scope move. The new revision retains the same lineage, text hash and original assertion date, but preparation supplies no predecessor. The only actions it attaches to the new revision come from the legacy inventory. Delivery checks existing native actions against the new document ID and an optional predecessor ID. The lookup is bank-scoped. It therefore misses accepted native actions from the old document in both the same-bank and cross-bank cases. The new source becomes accepted and the manifest reports ready.
