# Native correction and replay follow-up

The chat-edit job now separates writable chat facts from independently authored Memory corrections with exact source receipts. The correction is fixed context for the existing reviewer. Proposal validation excludes its IDs, and a native PATCH also requires the fact to belong to its recorded writable document. Readback checks the protected fact's native ID and text, and its native mention timestamp where the admitted snapshot provides it. A genuinely new chat assertion gets its own source. The verification stage still decides what may become visible.

The same source fence now covers saved compound actions in both dependency replay and exact resend. Every recorded source must still be allowed by the current bank and lineage before the original action text can reach the model. Ordinary cleanup and cancelled-edit recovery also verify the original and replacement receipt for every rebuilt reply at the final model dispatch. If a reply is withdrawn during its native rebuild, the old assertion, extracted facts and observation never reach that checker.

The three regression paths failed before the fixes. The tests inspect the native PATCH targets and serialized model requests. A live compound sibling can still be reviewed. A separately withdrawn sibling is withheld both in direct replay and when a resend rebuilds a dependent reply. A genuine later preference can be admitted from a new source while the earlier authored raw fact remains intact. The focused Node 22 run passed 252 tests across 12 suites. The typecheck reported 0 errors and 0 warnings. Scoped Biome and `git diff --check` passed.

## Date display decision

On November 19, the owner chose to omit an exact row date when its support does not certify one, while retaining the genuine dates in its source details. The native observation's `event_date` is the earliest supporting event date and `mentioned_at` is the latest supporting mention date. Neither identifies which date belongs to a particular wording. For example, native attached the earlier jasmine fact and later oolong fact to one oolong observation. Its `date` was August 4 and its latest mention was August 10. Memory keeps its existing internal sort and cursor date. The list and detail return `null` for a mixed-date row lacking a single certified date. New snapshot fingerprints record the effective per-fact assertion dates, and older snapshots use matching admitted source dates where possible. The date beside a changed conversation quotation now comes from that quoted revision's explicit edit timestamp. Unchanged resend and version dates retain their original recorded dates.
