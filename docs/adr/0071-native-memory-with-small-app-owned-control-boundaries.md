# ADR-0071: Native Memory with small app-owned control boundaries

Status: Accepted for implementation; deployment and real-user migration are not authorized by this ADR.

The old profile-memory extraction/consolidation system was inconsistent. Comparative synthetic evaluation favored native Hindsight; rebuilding extraction around it lost that advantage. The replacement therefore pins upstream Hindsight to `9fb28dbd724dc1ce4da7cb4c49008e601db76c5f` and keeps native extraction/consolidation. This supersedes ADR-0045's local-only prohibition for the replacement; legacy storage remains for gated rollback/migration.

AlfyAI owns authenticated opaque tenant routing, personal/project scope, source revisions and revocation intent, deliberately requested edit/remove transformations, the existing job engine, and an atomic published read snapshot. It does not add another extractor, nightly truth reconciler, semantic index or background scheduler. Personal memory is available everywhere; project memory remains project-only. Only an explicit minimal project summary may cross that boundary.

A small supported native TenantExtension verifies versioned server-generated HMAC credentials and uses native tenant migrations. A supported HTTP extension attests the observed engine checkout and schema binding and provides bounded inference transport. This is app-owned auth/routing/load control, not an engine fork. One native process/replica is required. Native fan-out and app curation go through the same transport admission point; foreground work is observed through content-free leases in existing SQLite. Unknown activity defaults to one request, healthy explicit idle allows six. Partial tracking failures can weaken downshift visibility, never the hard six-request background bound; chat is not failed by tracking errors. No universal cap on all app/model traffic is claimed.

The operational cost is a private PostgreSQL/native service, two narrow native extensions and paired secret/image/database lifecycle. The setup and rotation boundary is [deploy/hindsight/README.md](../../deploy/hindsight/README.md). Native service identity, tenant isolation, integrated edit/remove/replay, publication, failures, local model load and restore must pass independently; source-smoke success does not imply full acceptance. Real-user migration is separately authorized and preserves opt-outs. No destructive legacy schema cleanup is part of this implementation.
