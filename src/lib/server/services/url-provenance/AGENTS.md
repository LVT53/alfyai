# URL Provenance

- **An address the app requests without a click comes from the user's own words or a tool's result, never from the model's** ([ADR-0068](../../../../../docs/adr/0068-model-output-never-picks-an-address-fetched-without-a-click.md)): the model reads pages, emails and files a stranger wrote, and an `<img>`, a favicon or a page the server reads would hand whatever it put in the address to the address's owner. `src/lib/shared/url-provenance.ts` is the one vocabulary both sides compare in (the comparison key, the addresses in a text or payload, what a message's tool calls returned; a call's input never counts). In the browser, `sanitizeHtml` drops every fetching attribute (`src`, `srcset`, `poster`, `background`) unless its caller allows that exact address, and model markdown is sanitized `inert` (no forms, popovers, positioning CSS or classes the renderer did not write); a reply shows only its own image_search pictures, as Brave thumbnails through `/api/image-search/thumbnail`, and any other image as a link chip. On the server, `src/lib/server/services/url-provenance/` holds the per-user, in-memory source ledger (the only hosts and thumbnails the favicon and thumbnail routes and report favicons fetch) and the per-turn check that `fetch_url` and `produce_file` pictures pass, where the output of a tool the model writes itself (`run_python`, `produce_file`, the artifact tools) is never a source (`NON_PROVENANCE_RESULT_TOOLS`; a new tool joins one of the two lists or a test fails), nor is the text of a connector result a local model summarised for a cloud chat model (only its candidates count: `decideLocalDistill` marks the tool call it runs in and the envelope stores `localDistilled` on it, so connector data is summarised through `decideLocalDistill` and nowhere else: it refuses outside a tool call, before the local model reads anything, and the one summary that is not a tool's result, the proactive block spliced into the prompt, asks with `decideLocalDistillForPrompt`; `connector-distill.test.ts` holds the list of who may ask); and every fetch the server makes on an address it did not pick itself goes through `src/lib/server/outbound/` (resolve, refuse any non-public answer, connect to what was checked, never follow a redirect). A new feature that loads, embeds or fetches an address on its own goes through these, and extends their tests with a real request count.
